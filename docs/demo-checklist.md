# Pre-Demo Checklist

Short checklist to run through before the quarterly docs-pipeline demo on Thursday:

- [ ] Confirm `docs/demo-brief.md` is present on the default branch.
- [ ] Confirm the README still renders on the default branch.
- [ ] Confirm the CI workflow at `.github/workflows/ci.yml` is in place.
- [ ] Open pull request `chore/tidy-notes` -> `main` titled "Tidy up notes for the demo" and keep it open for review.
- [ ] Verify the pull request appears in the repo's open pull requests.
- [ ] Confirm the workflow run for this branch reports a pass.
- [ ] Post a summary comment on the pull request naming every file it touches.
